### Evaluación
La evaluación del ramo se compone de:

#### Individual (50%): Controles + Control Recuperativo
- **4 controles** durante el semestre.
- **1 Control Recuperativo (CR, abierto)** de toda la materia de la asignatura. 
- `PC`: promedio de controles. Se considera para el promedio los **4 mejores controles**, incluyendo el control recuperativo.

#### Prácticos (opcionales)
- Se ofrece **un práctico por cada control** (no aplica para el CR).
- Cada práctico entrega **puntos adicionales** que se suman al control correspondiente:
  - Máximo **10 puntos extra** por control.
  - El puntaje del control **satura en 100**.

#### Grupal (50%): Proyecto
- Trabajo en grupos de **3–4 integrantes**.
- **3 hitos** (80% del proyecto) + **evaluación del profesor** (20%).
- Definiciones:
  - `PP`: promedio del proyecto (hitos).
  - `EP`: evaluación del profesor.
  - `NP`: nota del proyecto.
- Cálculo del proyecto: `NP = 0.8*PP + 0.2*EP`

#### Cálculo de nota final y aprobación
- Nota final base: `NF = 0.5*PC + 0.5*NP`
- Condiciones para aprobar: `PC >= 50` y `NP >= 50`.
- Si **solo una** de las dos condiciones no se cumple, se aplica ponderación asimétrica:
  - Si `PC < 50`: `NF = 0.95*PC + 0.05*NP`
  - Si `NP < 50`: `NF = 0.05*PC + 0.95*NP`
- Si ambas condiciones se cumplen (o ambas no se cumplen), se usa la fórmula base `NF = 0.5*PC + 0.5*NP`.

## Cómo usar este repositorio

### 0) Herramientas recomendadas
- Linux, `gcc`, `g++`, `make`, `git`
- Para depuración: `gdb` y `valgrind` (unidad 04)
- Jupyter (opcional) para abrir `.ipynb`
- Para Qt (unidad 06): Qt6 + QtCreator y CMake

### 1) Leer el material de clases
Cada unidad incluye usualmente un Notebook `.ipynb` y su respectivo archivo `.pdf` de exportación

### 2) Compilar y ejecutar ejemplos (C/C++)
Recomendado trabajar en Linux. Compilar y ejecutar programas según lo indicado en cada unidad.

Para depuración y calidad de código, se sugiere usar herramientas como `gdb` y `valgrind` (cuando aplique).

### 3) Qt (interfaces gráficas)
En `06_QtLibrary/` encontrarás ejemplos y talleres.
Hay material con **CMake** (por ejemplo en `06_QtLibrary/examples/`) y talleres con proyectos `.pro` en `06_QtLibrary/Taller/` que puedes abrir con **Qt Creator**.
